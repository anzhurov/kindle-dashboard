# Підготовка Kindle Paperwhite 3

Ваш пристрій: PW3 (7 gen), серійник `G090G1…`, прошивка **5.9.2.0.1**.

## 0. Поки що не оновлюйте прошивку

Нові прошивки закривають вразливості, через які працює джейлбрейк. До завершення всіх кроків
тримайте Kindle в авіарежимі, а Wi-Fi вмикайте лише тоді, коли інструкція цього вимагає.

## 1. Резервна копія

По USB збережіть усе, що закидали вручну (папка `documents/`). Книги з Amazon просто знову
завантажаться з хмари. Деякі методи джейлбрейку роблять скидання до заводських налаштувань.

## 2. Джейлбрейк

Метод залежить від точної версії прошивки, тому беріть інструкцію саме під свою:
- MobileRead Wiki → *Kindle Jailbreak* / *5_x Jailbreak*;
- зведена таблиця методів за версіями: https://kindlemodding.org/jailbreaking/

Для версій до 5.16.2.1.1 зазвичай підходять **WatchThis** або **LanguageBreak**.
Перевірте, що обраний метод підтримує саме PW3 і вашу версію прошивки.

## 3. Після джейлбрейку

1. Встановіть **hotfix**: він зберігає джейлбрейк, якщо прошивка все ж оновиться.
2. Встановіть **MRPI** (інсталятор пакетів) і **KUAL** (лаунчер меню).
3. **Заблокуйте OTA-оновлення.** Найпростіший спосіб: створіть у корені Kindle по USB порожню **папку**
   з назвою `update.bin.tmp.partial`. Детальніше про це в розділі OTA-блокування на kindlemodding.org.
4. Перевірте: на домашньому екрані з'явилась «книга» KUAL, і вона відкривається.

Далі переходьте до розділу «Kindle» в [README](../README.md).
